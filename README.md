# Home Assistant Minecraft Add-ons

A collection of Home Assistant add-ons for running Minecraft servers.

## Add-ons in this repository

| Add-on | Description |
| ------ | ----------- |
| [Minecraft Geyser Server](minecraft-geyser/) | Paper server with Geyser/Floodgate for Java + Bedrock support |

## Installation

[![Add repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fmegakid%2Fha-minecraft-addons)

Or add it by hand. Home Assistant 2026.2 renamed add-ons to apps:

1. Go to **Settings → Apps** and open the store
2. Click the menu (⋮) in the top right → **Repositories**
3. Add this repository URL:
   ```text
   https://github.com/megakid/ha-minecraft-addons
   ```
4. Find the add-on you want in the store and click **Install**
